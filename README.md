# Employee Payroll Management System

A full-stack Employee Payroll Management System developed using React.js, Spring Boot, and MySQL.

## 🚀 Technologies Used

### Frontend
- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Maven
- REST APIs

### Database
- MySQL

## 📌 Features

- Employee Management
- Employee Attendance Management
- Leave Management
- Payroll Management
- Payslip Management
- Dashboard
- REST API Integration
- MySQL Database Integration
