# Employee Payroll Management System - Backend

A backend application for managing employees, attendance, leave, payroll, and payslips.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST APIs

## 📌 Features

- Employee Management
- Employee Attendance Management
- Leave Management
- Payroll Management
- Payslip Management
- Dashboard APIs
- MySQL Database Integration
