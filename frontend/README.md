# Employee Payroll Management System - Frontend

A modern frontend application for an Employee Payroll Management System built using React and Vite.

## 🚀 Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

## 📌 Features

- Employee Management
- Employee Attendance Management
- Leave Management
- Payroll Management
- Payslip Management
- Dashboard
